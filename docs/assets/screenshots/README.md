# Device screenshots

Empty on purpose. Every image currently in `docs/assets/mockups/` is a **generated mockup**, not a
capture, and none of them belongs here.

Real captures go in this directory, named `<slot>-<screen>.png`, where `<slot>` is one of
`lowend`, `midrange`, `tablet`. The capture procedure and the caption rules are in
[`docs/UI_CHECKLIST.md`](../../UI_CHECKLIST.md), section 9.

Until files exist here, no release note may describe a screen as working on a device (B7).
